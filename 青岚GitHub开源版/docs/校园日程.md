# 青岚 · 校园日程

在左侧选择“校园日程”（日历图标）。课表、备忘录和散文功能彼此独立，不上传日程数据，也不需要联网。

## 第一次使用

1. 先设置学期开始日期和结束日期，程序自动计算总周数。包含开学日的那一周算第一周，每周从周一到周日。学期外的日期不排课。
2. 页面最上方显示当前学期周次和单双周。开学前、学期结束后会显示相应状态。
3. 用“上一周 / 下一周”浏览周课表，“本周”回到当前周。若当前不在学期内，会定位到首周或末周。
4. 点“时段设置”，自定义每一行的名称、开始和结束时间。可以是一节课，也可以是连堂课，最多 20 行。时段不能重叠，不支持一个上课时段跨过午夜。

## 课程

- 点击空白格或“＋课程”，填写课程名称、老师、教室、星期、时段、周次和色签。
- 周次支持：`每周`、`单周`、`双周`、`1-4周`、`1-8单周`、`1-4,7,9-12`；中文逗号和顿号也可使用。
- 同一格可以排单双周不同的课程；实际上课周重叠时会拒绝保存，并提示冲突。
- 点击课程编辑或删除；“全部课程”包含其他周次的课程。删除课程需要再次确认，会移除它的全部周次安排。
- 修改时段的名称或时间，课程关联会保留。删除有课程的时段之前，须先调整或删除相关课程。
- 缩短学期前，须先修改超出新学期周数的课程，避免静默丢失安排。

## 备忘录

- 点击“＋记一件事”，填写事件与日期时间。勾选“这是一个时间段”可设置结束日期时间，允许跨天。
- 课表下方默认显示未删除事项中开始时间最早的三项，按时间升序。过期事项标为“已过时间 · 待处理”，不会自动丢弃；可展开查看全部。
- 当前周中有备忘录的日期，会在“周几”标题下显示醒目的橙色下划线；悬停显示当天事项数。跨天时间段会标记涉及的所有日期，结束时间恰好是午夜时不标记后一天。删除最后一项后，对应标记消失。
- 点击事项可编辑；右侧 `✓` 弹出确认框。只有选择“确认删除”才删除，取消不会改变数据。删除后下一项会补上，重启不会重复出现。
- 这是单次、本地备忘录；没有后台弹窗、系统通知或自动重复提醒。

## 数据与备份

日程单独保存在 `%LOCALAPPDATA%\QingLanCommunity\campus.json`，不混入收藏或随心记。保存采用临时文件替换，并保留上一版 `campus.json.bak`，不会自动恢复旧数据，以免已删除事项复活。多个程序窗口同时修改时，会要求刷新后再保存，避免互相覆盖。

首次进入不会预填示例课程或备忘录。测试使用临时生成的虚构数据。发送程序或提交源码时，不要附带自己的日程数据目录。
