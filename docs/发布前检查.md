## 上传源码

1. 在自己的 GitHub 账户创建一个空仓库，例如 `QingLan`。本地已包含 README、LICENSE 和 `.gitignore`，无需再创建重复文件。
2. 上传本源码目录中的文件和子目录，包括点号开头的配置文件。不要上传同级 ZIP、旧程序备份、个人数据或运行程序目录。
3. 上传后确认根目录能看到 `README.md`、`LICENSE`、`QingLan.slnx`、`src`、`tests`。
4. 仓库简介可使用：“面向大学生的 WinUI 3 阅读与校园日程应用，支持每日散文、随心记、课表和备忘录。”

项目已发布于 https://github.com/youchenghao2006-lab/QingLan 。源码、README、LICENSE 和构建配置位于仓库根目录；不要再次套一层文件夹上传。

## 发布运行程序

源码公开与运行版发布是两件事。以后需要让不开发的朋友使用，可运行发布脚本，将整个 `artifacts/publish` 文件夹打包，再上传 GitHub Releases。脚本会附带项目 LICENSE、第三方说明、使用文档，以及已还原 NuGet 包的许可文件和元数据清单；分发前仍需按实际组件核对许可要求。不要只复制 EXE，也不要把数百 MB 的运行库提交到源码仓库。
