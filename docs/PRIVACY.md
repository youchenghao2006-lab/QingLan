# 隐私与数据

## 本地数据

开源版默认使用 `%LOCALAPPDATA%\QingLanCommunity`。收藏、随心记、字体设置、下载文章和校园日程分别存为 JSON；这些是明文文件，不是加密保险箱。同一 Windows 账户下能读取这些文件的其他软件也可能访问内容。

应用自身不上传随心记、课表或备忘录，不包含账户、广告或分析上报代码。底层 Windows、.NET 和 SDK 的行为受其各自设置及隐私条款约束。没有语音生成请求。

本地保存可能产生 `.bak`、损坏文件副本及手动迁移快照。界面“删除”表示该记录不再由正常数据加载显示，不等于安全擦除磁盘上的所有历史副本。彻底清理时应先退出应用，再检查自己备份的数据。

## 网络访问

- 启动、跨日或手动刷新会请求 `https://zh.wikisource.org/w/api.php`，请求分类和页面内容，不附带用户笔记或课程数据。
- 网站会接收到网络连接通常包含的 IP、User-Agent 等信息。点击原文链接会在浏览器访问网站，适用浏览器和网站的隐私设置。
- 开发时 NuGet 还原会访问配置的包源；这与运行时阅读取文是不同的网络操作。

## 测试和旧数据

`QINGLAN_DATA_DIR` 可指定单独数据目录用于开发测试。不要把它指向原程序正在使用的数据目录；开源版样例文章 ID 与原版不同，混用可能影响收藏映射。自动测试只使用系统临时目录。

旧版迁移代码保留用于开发兼容性测试，但不自动扫描原程序的数据。只有明确设置 `QINGLAN_LEGACY_DIR`，或在新数据目录创建 `legacy-import` 后，首次加载才尝试导入其中的旧格式文件。它不是完整的旧应用迁移向导；尤其原版数字索引收藏依赖原来的 60 篇文章顺序，不适合直接导入本版。请勿指向真实数据来试验，也不要公开导入快照。

## 提交前检查

不要提交私人截图、真实日程、文章缓存、Windows 用户目录、令牌、证书、个人邮箱或未脱敏日志。`.gitignore` 只是辅助，不会自动保护已经提交过的文件。
